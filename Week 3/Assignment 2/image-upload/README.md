# Image Upload Feature

A simple full-stack image upload project built with React, Express, and Multer.

## Tech Stack

- Frontend: React + Vite + JavaScript + CSS
- Backend: Node.js + Express.js + Multer

## Project Setup

### 1. Install client dependencies

```bash
cd client
npm install
```

### 2. Install server dependencies

```bash
cd ../server
npm install
```

### 3. Start the backend

```bash
cd server
npm start
```

### 4. Start the frontend

```bash
cd client
npm run dev
```

Open the frontend in the browser at:

```bash
http://localhost:5173
```

The backend runs at:

```bash
http://localhost:5000
```

## Features

- Select image
- Preview selected image
- Validate file type and file size
- Upload to backend using FormData
- Show loading and success/error messages
- Display uploaded image
- Upload another image
